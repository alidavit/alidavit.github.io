# Ali Davit — Software Engineer Portfolio

This repository contains the source code for Ali Davit's personal software engineering portfolio website.

The site presents selected web applications, backend systems, infrastructure work, technical skills, and contact information in a simple responsive interface.

## Features

- Responsive portfolio layout for desktop and mobile
- English-language navigation and content
- Filterable project portfolio
- Interactive project detail dialog
- Mobile navigation menu
- Scroll reveal animations
- Dynamic copyright year
- Lightweight static HTML, CSS, and JavaScript

## Featured work

- Employee Tracking
- UniGuardZ
- OEE Dashboard Web
- HCForm Web
- Simple CashFlow System
- Doorlock and Payroll
- PTT Management System
- Residual Oxygen Online

## Project structure

```text
.
├── index.html   # Main portfolio page
├── style.css    # Layout, typography, and responsive styling
└── script.js    # Navigation, filters, dialog, and animations
```

## Run locally

Because this is a static website, no build step is required. Open `index.html` directly in a browser, or serve the folder with any local web server:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Customization

Update the following items in `index.html` and `script.js` to personalize the site:

- Introduction and about section copy
- Project names, descriptions, categories, and technology tags
- Email address and social links
- Skills and technology list
- Project dialog details
